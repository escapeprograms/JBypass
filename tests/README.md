# tests

CPU unit tests on tiny randomly initialised models of two architectures (Qwen3-shaped and
GPT-2-shaped), each described only by a `ModelProfile`. They use the real Qwen3 tokenizer
(small cached download); no model weights are downloaded. Run: `python -m pytest tests`.
Files are flat (no `tests/model/` folder, which could shadow the `model` package on import).

- `conftest.py` — profiles, settings and builders (`tiny_qwen3`, `tiny_gpt2`, `build_qwen`, `build_gpt2`); fixtures `tokenizer`, `lm` (runs a test once per architecture), `qwen_lm`; `random_ids` for raw forward passes; `synthetic_js(lm)`: a JSpace stand-in with a real `jlens.JacobianLens` of identity matrices (lens vectors = unembedding rows), band `[1]`, `readout_stats=None`; `synthetic_stats(js, seed=0)`: a `ReadoutStats` for `js.band` (random mean, positive std, every token counted once, `js.lm`'s profile name).
- `dummies.py` — test-only interventions: `Identity` (records its input), `ZeroOut`, `Replace` (applies a function once the sequence reaches a length).
- `test_model_config_loading.py` — YAML loading, `prefit_lens` parsing, `--device` override, profile-name check; `RunConfig.jspace` / `config_dir`; `jspace_config`: no (or an empty) `jspace:` section gives exactly `JSpaceConfig()`, overrides apply, an unknown key raises naming it, `readout_stats_dir` resolves relative to the config folder (default stays `stats`), `band_layers` becomes a tuple and anything but two ints raises, `fit_checkpoint_every` defaults to 10 and takes `null` (None) or an integer from YAML; `configs/exp3.yaml` gives `band_layers == (8, 26)`, `stats/exp3` and otherwise equals `run.yaml` (helper `_run_yaml_with`: run.yaml copy plus a `jspace:` section); sizes read from the model, left padding, `token_ids`, and the post-norm `hidden_states` fact.
- `test_model_hooks.py` — identity vs zero-out, hook removal on exit and exception, capture shapes, `unembed(last capture) == logits`, post-intervention capture, gradients through interventions, tensor/tuple block-output normalisation, `PerRow` edits only its own row, passes gradients, and rejects a wrong batch size.
- `test_model_inference.py` — chat template and kwargs, left padding, batched equals single (logits, loss, generation), `generate` returns only new text and stops at EOS, `greedy_tokens` calls its provider once per step with the grown sequence, `generate` equals the pre-refactor loop, `sequence_nll` sums and `encode(max_length)` truncation, `forward_residuals` shapes and post-intervention capture (a `ZeroOut` layer reads as zeros).
- `test_model_lora_training.py` — collate text and labels (generic `to_text`), batch cycling, hooks still fire after LoRA, fp32 adapter over bf16 base, `adapter_disabled`, save/load round trip, `saved_profile` reads the saved name, wrong-profile load raises, only adapters change, loss falls, factory called once per batch, interventions sit in the training graph.
- `test_jspace_model.py` — `ProjectOut` on a left-padded batch removes the vectors at every editable position and leaves each row's first real token and its padding unchanged; on one unpadded row the edit is bit-identical to editing `h[:, skip_first:]`; `lens_view` restores `requires_grad` and train mode before and after `attach_lora`; jlens's encoding equals `lm.token_ids` for Qwen; `lens_logits` applies interventions inside jlens's forward; `residual_logits` equals `lm.unembed` under an identity lens, equals the model's output logits at an unfitted final layer, and raises for an unfitted non-final layer; `readout_layers` adds the final layer; `load_lens` rejects a wrong `d_model`, missing layers and a profile with no lens, and accepts a fitting lens; `layer_range` values and its three invalid cases; the default fractions give layers 11-26 on 28 layers; `load_jspace`'s band: `band_layers` sets it (also from a run.yaml `jspace:` section via `jspace_config`), without it the fractions do, and a band layer the lens lacks or past the model raises (helpers `_all_layers_lens`, `_no_stats`); `profile_stats_path` equals `default_stats_path`; `fit_to_file` on two short prompts (`FIT_PROMPTS`), bare and with LoRA attached, saves a lens that `load_lens` accepts with every layer below the final one and writes `<out>.ckpt`; fitting 1 prompt and then 2 to the same `out` equals a fresh 2-prompt fit and jlens logs that it resumed after 1 prompt (the extend property; helper `_assert_full_lens_file`).
- `test_jspace_baseline.py` — `collect_readout_stats` equals a direct per-text computation over editable positions (left-padded batches, exclusions); excluded ids drop out of that token's count and `caps` refuses a token with count 0; `caps` is `mean + z * std` and rejects unknown layers; save/load round trip; `load_readout_stats` rejects another model name, another vocab size, and a missing band layer.
- `test_jspace_clamp.py` — `set_readout` with zero targets equals `_project_out` with the QR basis; `ReadoutClamp.edit` gives `min(readout, cap)`, leaves rows already below their caps bit-identical, and leaves the orthogonal complement unchanged; on a left-padded batch it keeps each row's first real token and padding; `load_jspace` raises for a missing explicit `stats_path`, gives `readout_stats=None` with no file, and loads the default `<readout_stats_dir>/<profile>.pt` (helper `_cfg`: tmp stats folder and band `(0, 1)`, since the default fractions reach past the 3-layer tiny model).
- `test_jspace_eval.py` — model-free: loaders, split leakage, the dataset generator (unique names, each bridge in one category, bridge absent from its own two-hop prompt, hop-2 prompt = relation template filled with the bridge phrase, `swap_to` a different bridge of the same category, every bridge has Chinese spellings and `check_bridge_zh` names missing / unknown bridges, the committed JSON equals a fresh build), `bridge_zh` loading (paper sets give `()`), `single_token_ids` keeps single-token spellings in order and `token_variants` still returns unique single-token ids, answer matching, probe separability and subject leakage, decomposition recovery, projection, and swap math; `show_table.describe` rebuilds both accuracy tables and the item count from synthetic records, and `show_table.expand` sorts glob matches and raises on a pattern with no match.
- `test_evaluation_model.py` — `greedy_continuation` returns the decoded tokens and the first id; every builder returns a sequence (`()` for `none`) on band layers (with `synthetic_stats` set); `bridge_clamp` builds one `ReadoutClamp` on the band, both clamp builders raise mentioning `run_readout_stats` without stats, and `wrong_bridge_clamp` caps the `swap_to` tokens; `run_readout_stats.reference_texts` gives each prompt and its own bridge's variants; `tokenizer_readable_items` equals `readable_items` (unreadable bridge dropped, no `swap_to` kept); random builders repeat under the same `item_rng`; `interventions_for_item` rebuilds identical random ablations on every call, equal to a fresh-rng build; perplexity is token-weighted with truncation and short texts skipped; `is_answer_token` rejects whitespace, quotes and filler words; `answer_index` on real Qwen tokenizations skips filler, a leading quote, the bare space before a digit and EOS, and falls back to 0.
- `test_viz.py` — viewer core without gradio or network: `viz.yaml` paths (`runs_dir`, `lenses_dir`, the committed `lenses_dir` is `lenses/` beside `runs/`) and `null` split/dictionary files; CC-CEDICT on inline sample lines (both bracket forms, traditional and simplified keys, proper nouns last, `#`/blank/CRLF lines skipped, malformed line raises with its number, no entries raises; longest-match segmentation, unknown runs, whitespace, U+FFFD; gzipped round trip with BOM; missing file names the path and download page); glosses (`is_foreign`, only foreign tokens keyed, Kana has no entries, `context_ids` from `ctx_offset`, a real tiny-model slice); `with_glosses` (bootstrap still extracts, payload round-trips, `</script>` in a sense cannot close the tag, srcdoc round trip, no `</body>` raises, static files hold no closing tags); a jlens contract test (every selector/behaviour `gloss.js` relies on is still in `jlens.vis.PAGE_TEMPLATE`); catalog (only lens profiles, adapter filtering, non-empty splits, `NEEDS_SWAP` and `None`-field filtering, `buildable_conditions(has_stats, ...)` drops `NEEDS_STATS` only when `has_stats` is False, seeded random pick, `examples(tokenizer, ...)` drops unreadable bridges and filters splits; `refit_lens_file` is `<adapter folder>.pt` or `<profile>.pt`, `with_refit_lenses` sets `.lens` only for existing files and keeps labels, `fit_command` has `--adapter` only for adapters); `ResultCache` (round trip, two models on one question both kept, a put for another question drops the old entries, `entries` in insertion order); `responses_table` (header, rows in order, yes/no, `|`, newlines and `<` escaped; `""` for no rows) and `no_refit_lens_note` (escaped label and command, restart hint); `Session` loads once per choice and frees the old model; `attach_refit` on a real `load_jspace` with tmp lens files (helper `_save_lens`) shares the model, lens view, band and stats and reads the file's lens, None gives one reader; `run_example` equals `greedy_tokens` and eval scoring, with `answer_index`/`shown_ids` from `evaluation.scoring.answer_index`; slice shapes over prompt + shown response, parity with `jlens.vis.compute_slice`, replay reproduces generation under every condition (with `synthetic_stats`), pins tracked and `max_tracked` cap, single-token Chinese `bridge_zh` spellings pinned and multi-token ones not (empty `bridge_zh` gives the old pins), `bridge` changes the slice, a perturbed top-1 is reported but the last shown position is never checked; `run_slices` with one reader equals `run_slice`, and with a second reader on random J matrices (helper `_random_lens_js`, a second `synthetic_js` on the same model) makes exactly one `forward_residuals` call, gives a second slice equal to `slice_from_ids(own, ...)` with interventions built from the original lens, differing below the final layer and equal at it (helper `_assert_same_slice`); srcdoc round trip, embedded page metadata (template memo seeded so d3 is not fetched), summary text (shown positions and answer-token position, full response kept, bridge with its Chinese spellings), item card (bridge label with and without `bridge_zh`). App tests (skipped without gradio) with a fake `Session` returning `Loaded(synthetic_js)` (helpers `_app_context`, `_offline_pages` seeds the jlens template so no d3 fetch, `_counting_app` counts loads and wraps `viz.app.run_example` to count generations): `build_app` constructs and the choice handlers offer only valid splits/fields/conditions without a model (no clamp conditions without stats); in the built app's config every event chain ends in a `show` step (or is Run) and only `show` and Run use the model queue; `run_app.profile_choices` keeps the session profile and its adapters and raises for a profile with no prefit lens; `on_run` returns a summary starting with `**Model:** tiny`, an `<iframe` embed titled `original lens (1 prompts)` and, with no refit lens, a refit pane holding the fit command; it raises `gr.Error` with no example; `on_run` embeds the gloss data with a sample dictionary and not with `None`; with a refit reader the refit pane is its own `<iframe` titled `refit lens (2 prompts)` with its own gloss data; `on_show` before a run gives the placeholder (no table, empty panes) with no load, `on_run` twice gives the same output with one load and one generation, a second model label loads again, `on_show` back on the first equals its `on_run` output (the table now with both runs) with no further load or generation, and after a run on another item the old one shows the placeholder; the table lists a question's runs in run order and is empty on a question with none.
- `test_finetune.py` — `item_text`, training conditions are eval conditions, and training under `condition_factory("bridge")` with a synthetic lens calls the factory once per batch with one `PerRow` of per-row `ProjectOut`s, the loss falls, and only adapter weights change; training under `condition_factory("bridge_clamp")` with `synthetic_stats` gets per-row `ReadoutClamp`s on the band and finite losses (shared helper `_train_checking_rows`).
