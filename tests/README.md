# tests

CPU unit tests on tiny randomly initialised models of two architectures (Qwen3-shaped and
GPT-2-shaped), each described only by a `ModelProfile`. They use the real Qwen3 tokenizer
(small cached download); no model weights are downloaded. Run: `python -m pytest tests`.
Files are flat (no `tests/model/` folder, which could shadow the `model` package on import).

- `conftest.py` — profiles, settings and builders (`tiny_qwen3`, `tiny_gpt2`, `build_qwen`, `build_gpt2`); fixtures `tokenizer`, `lm` (runs a test once per architecture), `qwen_lm`; `random_ids` for raw forward passes; `synthetic_js(lm)`: a JSpace stand-in with a real `jlens.JacobianLens` of identity matrices (lens vectors = unembedding rows), band `[1]`.
- `dummies.py` — test-only interventions: `Identity` (records its input), `ZeroOut`, `Replace` (applies a function once the sequence reaches a length).
- `test_model_config_loading.py` — YAML loading, `prefit_lens` parsing, `--device` override, profile-name check, sizes read from the model, left padding, `token_ids`, and the post-norm `hidden_states` fact.
- `test_model_hooks.py` — identity vs zero-out, hook removal on exit and exception, capture shapes, `unembed(last capture) == logits`, post-intervention capture, gradients through interventions, tensor/tuple block-output normalisation, `PerRow` edits only its own row, passes gradients, and rejects a wrong batch size.
- `test_model_inference.py` — chat template and kwargs, left padding, batched equals single (logits, loss, generation), `generate` returns only new text and stops at EOS, `greedy_tokens` calls its provider once per step with the grown sequence, `generate` equals the pre-refactor loop, `sequence_nll` sums and `encode(max_length)` truncation, `forward_residuals` shapes and post-intervention capture (a `ZeroOut` layer reads as zeros).
- `test_model_lora_training.py` — collate text and labels (generic `to_text`), batch cycling, hooks still fire after LoRA, fp32 adapter over bf16 base, `adapter_disabled`, save/load round trip, `saved_profile` reads the saved name, wrong-profile load raises, only adapters change, loss falls, factory called once per batch, interventions sit in the training graph.
- `test_jspace_model.py` — `ProjectOut` on a left-padded batch removes the vectors at every editable position and leaves each row's first real token and its padding unchanged; on one unpadded row the edit is bit-identical to editing `h[:, skip_first:]`; `lens_view` restores `requires_grad` and train mode before and after `attach_lora`; jlens's encoding equals `lm.token_ids` for Qwen; `lens_logits` applies interventions inside jlens's forward; `residual_logits` equals `lm.unembed` under an identity lens, equals the model's output logits at an unfitted final layer, and raises for an unfitted non-final layer; `readout_layers` adds the final layer; `load_lens` rejects a wrong `d_model`, missing layers and a profile with no lens, and accepts a fitting lens.
- `test_jspace_eval.py` — model-free: loaders, split leakage, the dataset generator (unique names, each bridge in one category, bridge absent from its own two-hop prompt, hop-2 prompt = relation template filled with the bridge phrase, `swap_to` a different bridge of the same category), answer matching, probe separability and subject leakage, decomposition recovery, projection, and swap math; `show_table.describe` rebuilds both accuracy tables and the item count from synthetic records, and `show_table.expand` sorts glob matches and raises on a pattern with no match.
- `test_evaluation_model.py` — `greedy_continuation` returns the decoded tokens and the first id; every builder returns a sequence (`()` for `none`) on band layers; random builders repeat under the same `item_rng`; `interventions_for_item` rebuilds identical random ablations on every call, equal to a fresh-rng build; perplexity is token-weighted with truncation and short texts skipped.
- `test_viz.py` — viewer core without gradio or network: `viz.yaml` paths and `null` split file; catalog (only lens profiles, adapter filtering, non-empty splits, `wrong_bridge` and `None`-field filtering, seeded random pick, unreadable bridges dropped); `Session` loads once per choice and frees the old model; `run_example` equals `greedy_tokens` and eval scoring; slice shapes, parity with `jlens.vis.compute_slice`, replay reproduces generation under every condition, pins tracked and `max_tracked` cap, `bridge` changes the slice; srcdoc round trip, embedded page metadata (template memo seeded so d3 is not fetched), summary text, item card. Two app tests (skipped without gradio) with a fake `Session` returning `synthetic_js`: `build_app` constructs and the choice handlers offer only valid splits/fields/conditions; `on_run` returns the summary and an `<iframe` embed, and raises `gr.Error` with no example.
- `test_finetune.py` — `item_text`, training conditions are eval conditions, and training under `condition_factory("bridge")` with a synthetic lens calls the factory once per batch with one `PerRow` of per-row `ProjectOut`s, the loss falls, and only adapter weights change.
